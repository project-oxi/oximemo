### P0 — 메모 저장 후 목록에 안 뜨는 버그

**현상:** 메모를 입력하고 저장을 눌러도 메모 목록에 나타나지 않음.

**관련 파일:**
- `apps/desktop/src/components/NoteDetail.tsx` — 디테일 다이얼로그 + autosave
- `apps/desktop/src/components/NoteEditorForm.tsx` — 편집 폼 (body, tags, category select)
- `apps/desktop/src/components/CardGrid.tsx` — 메인 카드 그리드, `listNotes` 호출
- `apps/desktop/src/lib/api.ts` — IPC 호출 (createNote, updateNote, listNotes)
- `apps/desktop/src-tauri/src/lib.rs` — Rust IPC 핸들러
- `crates/oxinot-core/src/vault.rs` — Vault create_note / list_notes

**의심 포인트:**
- `createNote`가 제대로 완료되지 않거나, 완료 후 `notes:changed` 이벤트가 안 감
- `listNotes` cursor pagination 문제
- `NoteEditorForm`의 confirm 버튼이 실제로 IPC를 호출하는지 확인
- Rust 쪽 `create_note`에서 에러가 발생하는데 무시되고 있는지
- `autosave`는 되는데 `notes:changed` 이벤트 발행 누락

**해결 후 반드시 smoke test:**

1. 앱 실행
2. '+' 버튼으로 새 노트 생성
3. 내용 입력 후 저장/confirm
4. 목록에 즉시 나타나는지 확인
5. 앱 재시작 후에도 해당 노트가 목록에 있는지 확인

### 3. 빠른 캡쳐 화면 완전 재구성 (CaptureOverlay + QuickCaptureForm)

**현재:** 앱 화면의 일부가 그대로 떠있는 느낌. UI가 별로.
**요구사항:** Claude Code의 채팅 입력 필드 스타일로 완전히 새롭게 제작.

**디자인 방향:**
- [ ] 전체 화면이 아닌, **채팅 입력창 하나만** 떠있는 미니멀한 오버레이
- [ ] 마치 Claude Code에 채팅을 보내는 듯한 UX
- [ ] **슬래시 명령어 (`/`)** 로 카테고리 선택 가능
  - `/inbox`, `/todo`, `/note`, `/idea` 등 입력시 자동완성
  - 슬래시 명령어 팔레트 UI
- [ ] 기존 `QuickCaptureForm.tsx`의 slash-command 기능은 이미 존재하지만, 배치/UX가 부족
- [ ] CaptureOverlay의 창 크기/위치 재조정 (더 작고 집중된 형태)
- [ ] Enter로 저장, Esc로 닫기
- [ ] `/` 명령어로 카테고리 선택 + 메모 내용을 한 줄에 입력

**참고:**
- `doc/CAPTURE_SLASH_PALETTE.md` — 기존 디자인 초안 (미완료)
- oxios의 ⌘K command palette 패턴 참고
